# Real-Time Collaborative Canvas

A multi-user, multi-room real-time drawing application built using WebSockets.

## Features
- Live multi-user drawing
- Brush and true eraser
- Global undo/redo
- User presence list
- Room-based collaboration
- Real-time sync

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Canvas API
- Backend: Node.js, WebSocket (ws)
- Hosting: Netlify (Frontend), Render (Backend)

## Run Locally
```bash
cd server
npm install
npm start
